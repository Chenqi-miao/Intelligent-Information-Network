# 实验报告：基于深度学习的 ISP 网络流量预测模型对比分析

## 1. 摘要

本实验复现了论文"Comparative Analysis of Deep Learning Models for Real-World ISP Network Traffic Forecasting"，在 CESNET-TimeSeries24 数据集的机构级流量数据上，对比了 Mean、SARIMA、LSTM、GRU 四种模型的流量预测性能。实验采用 35:5:60 的时间顺序分割和 Z-score 标准化，评估了不同滑动窗口配置下的预测效果。结果表明：GRU 和 LSTM 表现接近（R² 中位数 0.145 和 0.116），均显著优于 Mean 基线（R² 中位数 -0.004）。SARIMA 在滚动预测策略下表现最强（R² 中位数 0.183），说明传统统计模型在公平比较下仍有竞争力。实验同时发现了真实网络流量数据中存在的季节性分布漂移问题，其对模型评估的影响值得关注。

## 2. 引言

ISP 网络流量预测是网络资源管理、拥塞控制和容量规划的关键技术。随着深度学习的发展，LSTM、GRU 等循环神经网络已被广泛应用于流量预测任务，但在真实大规模 ISP 数据上的系统性对比研究仍较为有限。

论文 "Comparative Analysis of Deep Learning Models for Real-World ISP Network Traffic Forecasting" 在 CESNET-TimeSeries24 数据集上对 10 种模型进行了系统对比。该数据集的独特价值在于其真实性和规模——覆盖捷克国家级科研教育网络 40 周的流量数据，包含机构级、子网级、IP 地址级三个层级。

本实验选取其中最具代表性的四种模型（Mean、SARIMA、LSTM、GRU），聚焦于机构级 n_bytes 指标的预测。与论文固定参数、不滚动拟合的 SARIMA 评估方式不同，本实验对 SARIMA 采用了滚动预测策略，使其在更公平的条件下与深度学习模型进行对比。

## 3. 数据与预处理方法

### 3.1 数据集

CESNET-TimeSeries24，捷克 CESNET 科研教育网络 2023 年 10 月至 2024 年 7 月共 40 周的流量数据。

使用**机构级（institutions）** 283 条时间序列，1 小时间隔聚合，以 `n_bytes`（传输字节数）为主预测指标。机构级数据缺失率约 1%，远低于 IP 地址级的 80%+，周期模式清晰，适合作为主实验数据集。

数据集的主要挑战：
- **时间序列间隙**：原始 CSV 只记录有数据的行，缺失时间点整行不存在（而非 NaN），需通过对齐时间轴来识别。
- **周期模式**：存在日周期（24h）和周周期（168h），为滑动窗口的选择提供了依据。
- **分布漂移**：部分机构受季节性影响（如暑假），测试集流量相较训练集骤降 10^4~10^5 倍，导致模型失效。

### 3.2 预处理流程

预处理流程包含以下步骤：

**时间轴对齐**：所有时间序列与完整时间戳表 `times.csv` 做 right merge，原数据中缺失的时间点以 NaN 标记，确保全时间轴对齐。

**缺失值填充**：机构级数据缺失率极低（~1%），采用零填充（zeros）。

**滑动窗口生成**：选取四种窗口配置：(24,24)、(168,24)、(168,168)、(744,168)。窗口按 `stride = prediction_window` 不重叠滑动，将一个连续时间序列切成 (training_window, prediction_window) 的样本对。

**时间顺序分割**：按时间顺序分割，不随机打乱。采用 **35% 训练 / 5% 验证 / 60% 测试** 的比例，对齐论文开源代码的分割策略。

**标准化**：采用 Z-score 标准化：

$$z = \frac{x - \mu_{train}}{\sigma_{train}}$$

其中 μ 和 σ 仅从训练集计算，验证集和测试集变换时使用训练集的参数，避免未来信息泄露。

### 3.3 模型

论文对比了 10 个模型，本实验选取其中最具代表性的 4 个：Mean（最简基线）、SARIMA（统计基线）、LSTM（循环神经网络代表）、GRU（循环神经网络代表）。

**Mean 基线**：预测值 = 输入窗口的均值，作为性能下限参考。

**SARIMA**：Seasonal AutoRegressive Integrated Moving Average，捕获时间序列的自回归结构、趋势和季节性。使用 (1,0,1)(1,0,1,24) 配置。与论文固定参数不同，本实验对 SARIMA 采用**滚动预测**策略：对每个测试窗口，使用截至当前的所有历史数据重新拟合模型，再进行预测。这使得 SARIMA 与深度学习模型在相同条件下获得公平对比。

**LSTM**：Long Short-Term Memory 网络。结构上采用双向单层 LSTM（hidden_size=100），取最后时间步的隐藏状态接 Linear 层输出 24 步预测。

**GRU**：Gated Recurrent Unit，将 LSTM 的遗忘门和输入门合并为更新门，参数更少。结构与超参数配置与 LSTM 一致。

## 4. 实验设置

### 4.1 超参数配置

|------|------|-----|--------|------|
| hidden_size | 100 | 100 | - | - |
| num_layers | 1 | 1 | - | - |
| bidirectional | True | True | - | - |

| batch_size | 16 | 16 | - | - |
| order | - | - | (1,0,1) | - |
| seasonal_order | - | - | (1,0,1,24) | - |

### 4.2 评估指标

**RMSE**（均方根误差）：

$$RMSE = \sqrt{\frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2}$$

**R²**（决定系数）：

$$R^2 = 1 - \frac{\sum_{i=1}^{N} (y_i - \hat{y}_i)^2}{\sum_{i=1}^{N} (y_i - \mu_y)^2}$$

**sMAPE**（对称平均绝对百分比误差）：

$$sMAPE = \frac{100\%}{N} \sum_{i=1}^{N} \frac{2|y_i - \hat{y}_i|}{|y_i| + |\hat{y}_i|}$$

## 5. 结果与分析

### 5.1 模型整体对比

在 212 条机构级时间序列上的对比结果（窗口 (24,24)，35:5:60 分割）：

| 模型 | R² 均值(裁剪后) | R² 中位数 | R²>0 占比 | RMSE 中位数 |
|------|----------------|-----------|-----------|------------|
| Mean | 0.005 | -0.004 | 46.7% | 4.1e8 |
| LSTM | 0.071 | 0.116 | 83.5% | 4.6e8 |
| GRU | 0.118 | **0.145** | 81.1% | 4.5e8 |
| SARIMA（滚动） | **0.175** | **0.183** | **91.5%** | 4.1e8 |

核心结论：**GRU 和 LSTM 均显著优于 Mean 基线，GRU 略优于 LSTM。** GRU 的 R² 中位数 0.145 高于 LSTM 的 0.116，81% 以上的序列 R² 为正，而 Mean 基线超过一半的序列 R² 为负（即不如猜均值）。

### 5.2 窗口配置对比

| 窗口 | LSTM R² 中位数 | GRU R² 中位数 |
|------|---------------|---------------|
| (24,24) | 0.098 | 0.097 |
| (168,24) | 0.095 | 0.099 |
| (168,168) | 0.046 | 0.063 |
| (744,168) | 0.032 | 0.047 |

随着预测窗口增大，模型性能呈下降趋势：**短期预测（24h）显著优于长期预测（168h）**。使用 1 个月的历史数据（744h）预测未来 1 周，其 R² 中位数不到短期预测的一半。这说明在该数据集上，流量预测的可靠性随预测跨度增加而明显衰减。

### 5.3 SARIMA 滚动预测的意义

论文报告 SARIMA 在所有模型中的表现是最差的之一（R² 大面积负值），但本实验发现，这主要是因为论文对 SARIMA 采用了"一次拟合，全测试集重复使用同一预测结果"的评估方式，而非模型本身能力不足。

在采用**滚动预测**策略（每个测试窗口重新拟合）后，SARIMA 的 R² 中位数达到 0.183，甚至略优于 LSTM 和 GRU。这一结果说明：

1. 在公平比较下，传统统计模型与深度学习模型的差距并非不可逾越
2. 滑动窗口评估框架天然偏向 DL 模型（单次 forward 即可完成预测），对需要逐窗口重新拟合的统计模型不利
3. SARIMA 的优势在于可解释性——其拟合系数（AR、MA、季节项权重）可以直接解读

### 5.4 数据分布漂移的影响

实验中发现一个影响评估可靠性的重要问题：**数据分布漂移**。部分机构级序列的流量呈现强季节性（如大学网络），当测试集落在暑假（6-7 月）时，测试集流量均值相比训练集骤降 10^4~10^5 倍。这种分布外推场景下的预测必然失败，导致 R² 出现极端负值（-10^7 ~ -10^9）。

该问题对模型评估的影响：
- **均值被极端值扭曲**：少数序列的极端 R² 负值使得整体均值完全失去意义
- **中位数是更稳健的指标**：不受极端值影响，应作为主要参考
- **裁剪策略**：参考论文做法，对 R² 做 clip(-10, 1) 处理，使统计量更具代表性

本实验采用 35:5:60 的分割比例可以部分缓解该问题（测试集更大、覆盖更广的时间段），但未能完全消除。这是真实网络数据不同于合成数据的重要特征，也是模型落地时需要考虑的实际问题。

### 5.5 预测可视化

见图 `experiments/02_analysis/figures/prediction_file0_all.png` 和 `file243_all.png`。

以 file=0（大型机构）为例，LSTM 和 GRU 的预测曲线与实际值高度吻合，RMSE 约 1.8e10，R² 约 0.60-0.73。Mean 基线则表现为一条水平直线（全局均值），完全无法捕捉流量波动。对于 file=243 这样的强季节性机构，所有模型在测试期均表现不佳，反映了分布漂移的挑战。

## 6. 总结与展望

### 主要发现

1. **GRU 和 LSTM 在 ISP 流量预测上表现接近**，R² 中位数约 0.12-0.15，显著优于 Mean 基线。GRU 以更少的参数实现了略优的性能。
2. **SARIMA 在滚动预测策略下表现不输深度模型**，挑战了论文"统计模型远不如 DL 模型"的结论，揭示了评估方法对模型排名的影响。
3. **短期预测（24h）效果显著优于长期预测（168h）**，R² 中位数随预测跨度增大而衰减约 50% 以上。
4. **数据分布漂移是真实网络流量数据集的核心挑战**，其对评估结果的影响值得关注。

### 局限性

- 本实验仅覆盖了机构级 `n_bytes` 指标，未对全部 18 个指标和三个层级进行全面实验
- SARIMA 滚动预测仅运行了 10 个测试窗口，与 LSTM/GRU 的 168 个窗口的对比存在样本量差异
- 超参数未进行系统搜索，使用了论文参考代码的默认值
- 数据分布漂移问题未完全解决

### 改进方向

- **模型可解释性**：对 LSTM/GRU 的预测进行 SHAP 值分析，理解模型学到了哪些时间步的重要模式
- **业务场景适配**：将预测结果映射到具体业务场景（骨干网、边缘节点、企业网络），建立模型-场景适配矩阵
- **多指标预测**：利用 `n_bytes`、`n_flows`、`n_packets` 等多变量信息进行联合预测，可能提升预测精度
